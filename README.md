# 🚀 CollabSpace

A modern real-time team collaboration platform built with React, Vite, Tailwind CSS, Framer Motion, and Supabase.

Live Demo: https://collabspacen.vercel.app/

---

# ✨ Features

## 🔐 Authentication
- User Signup & Login
- Secure Supabase Authentication
- Persistent Sessions
- Logout Functionality

## 🏢 Workspace Management
- Create Personal Workspaces
- Persistent Workspace Storage
- Dynamic Workspace Dashboard
- Search Workspaces

## 🤝 Collaboration System
- Invite Members via Email
- Shared Workspaces Section
- Multi-user Collaboration Architecture

## 🎨 Modern UI/UX
- Dark Neon SaaS Theme
- Glassmorphism Design
- Smooth Framer Motion Animations
- Responsive Layout
- Fixed Sidebar Navigation

## ⚡ Tech Stack
- React.js
- Vite
- Tailwind CSS
- Framer Motion
- Supabase
- Vercel
